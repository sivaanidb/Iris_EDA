# Iris Dataset Analysis Project

## Overview
This project is a beginner-friendly data analysis and machine learning tutorial in Python. It uses the famous **Iris flower dataset** to explore, clean, and visualize data using popular data science libraries.

---

## Requirements
To run this project, you need Python installed along with the dependencies specified in the `requirements.txt` file:
* `pandas`
* `numpy`
* `matplotlib`
* `seaborn`
* `scikit-learn`

You can easily install all dependencies using `pip` from your terminal or command prompt:
```bash
pip install -r requirements.txt
