# Iris Dataset Analysis Project

## Overview
This project is a beginner-friendly data analysis and machine learning tutorial in Python. It uses the famous **Iris flower dataset** to explore, clean, and visualize data using popular data science libraries.

---

## Requirements
To run this project, you need Python installed along with the following libraries:
* `pandas`
* `numpy`
* `matplotlib`
* `seaborn`
* `scikit-learn`

You can install them using `pip` commands inside your notebook or terminal:
```bash
pip install pandas matplotlib seaborn scikit-learn
